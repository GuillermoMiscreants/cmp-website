# Editing pages

Pages are built in Sanity Studio from sections and components. Visual choices are named variants. There is no panel for custom padding, colors, or fonts.

## Add a section

Open a page, then add to **Sections**. The insert menu is grouped under **Layout**.

- **Section** is an empty container. Put components inside it.
- Presets such as **Hero – centered** and **Feature grid** start with a useful arrangement. Nothing extra is stored to remember that it was a preset.
- **Logo marquee** and **FAQ** are sealed. They have their own fields and do not accept a stack of components.

## Add a component

Inside a section, add to **Content**. Groups:

- **Text** — eyebrow, heading, text
- **Actions** — button group (one to three buttons)
- **Media** — image, video
- **Layout** — spacer, divider, card grid, columns

Columns hold the same components, except another columns block or a card grid. A card grid holds cards only.

## Change a variant

Style fields sit in the collapsed **Style** group: width, background, spacing, alignment, button variant, and so on. Each value maps to a style that already exists in the site.

Heading **Level** is the semantic tag (one H1 per page). **Size** is only how big it looks.

## Reorder

In the Presentation preview, drag a section, a component inside a section, or a button inside a button group. The new order is saved on the document.

## What a sealed section is

A sealed section is a fixed layout with settings instead of a free stack of components. Use it for the logo marquee and the FAQ. Change its copy and background. Do not try to drop a heading into it; add a normal section for that.
